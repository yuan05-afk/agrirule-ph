# AgriRulePH Deliverables Index

This folder contains project-report deliverables tailored to **AgriRulePH** (Django + MySQL rule-based crop planning DSS for small-scale farmers in the Philippines).

## Deliverable Files

1. `01_Project_Guidelines_and_Problem_Identification.md`
- Real-world problem statement
- Target users
- Expected impact
- Scope and objectives

2. `02_Solution_Design_and_Implementation.md`
- System design and methodology
- Rule-based AI approach (no ML)
- Architecture and implementation mapping to actual modules

3. `03_Analysis_and_Evaluation.md`
- Testing scenarios
- Evaluation approach and metrics
- Current performance/behavior discussion
- Limitations and improvements

4. `04_Project_Report_Template_Filled_Guide.md`
- Full report structure from Cover Page to Appendices
- Section-by-section writing guide specific to AgriRulePH
- Ready-to-fill placeholders for your final PDF report

5. `05_Evidence_Artifacts_Checklist.md`
- Required screenshots/charts/tables/diagrams to capture
- Where each artifact appears in the report
- Defense-ready evidence checklist

6. `06_Architecture_Flowcharts_and_Pseudocode.md`
- System architecture diagram
- Core process flowcharts
- Pseudocode for inference and analytics logic

7. `07_Techstack.md`
- Full technology stack mapping by system layer
- Rationale for stack selection

8. `08_Steps_of_Implementation.md`
- Implementation phases from setup to testing and documentation
- Report-ready step-by-step development narrative

## How To Use

1. Fill all bracket placeholders like `[GROUP_MEMBER_1]`.
2. Copy finalized content into your official report document.
3. Export final report as PDF.
4. Include screenshots/charts listed in `05_Evidence_Artifacts_Checklist.md`.
