# 05. Evidence Artifacts Checklist (AgriRulePH)

Use this checklist to gather proof artifacts for your report and defense slides.

## A. Core Screenshots

- [ ] Home page hero + supported commodities section
- [ ] Consultation form (with dropdown guidance panel shown)
- [ ] Results page top-3 recommendation cards
- [ ] Results page crops-to-avoid section
- [ ] Results page top-10 expanded section
- [ ] Results page action recommendations section

## B. Analytics Screenshots

- [ ] Consultation Snapshot + Input Facts
- [ ] Top 10 Suitability Comparison
- [ ] Top Recommendation Podium
- [ ] Crop Category Opportunity Chart
- [ ] Condition Match Strength by Factor
- [ ] Crop Trade-Off Comparison
- [ ] Field Adjustment Opportunities
- [ ] Suitability Tier Groups
- [ ] What-If Analysis
- [ ] Recommendation Insights Table
- [ ] Cautions / Limitations block

## C. Dashboard/Admin Evidence

- [ ] Dashboard main page with counts (crops/rules/consultations)
- [ ] Crop management list or form
- [ ] Rule management list or form
- [ ] Consultation records view
- [ ] Django admin login and index (if included in report)

## D. Data and Logic Evidence

- [ ] Seed command run output (crop/rule count)
- [ ] Example consultation input payload
- [ ] Example inference output (top recommendations + avoid list + traces)
- [ ] What-if scenario output sample (before/after top crop)

## E. Diagrams to Include

- [ ] System architecture diagram
- [ ] Rule engine flowchart
- [ ] Consultation-to-results sequence diagram
- [ ] Analytics interpretation flow (optional)

## F. Tables/Charts for Report

- [ ] Scenario test table (inputs, expected behavior, observed result)
- [ ] Evaluation metrics summary table
- [ ] Limitations and improvement mapping table

## G. Quality Checks Before PDF

- [ ] All screenshots are readable and cropped cleanly
- [ ] All figure/table captions are present
- [ ] Section references in text match figure/table numbering
- [ ] No placeholder text remains (e.g., `[FILL]`)
- [ ] References formatted consistently
